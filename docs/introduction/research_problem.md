# From Pairwise PPI Prediction to Inductive Interactome Reconstruction

Protein-protein interactions (PPIs) are usually modeled as local decisions: given two proteins, predict whether they interact. This framing has made the problem tractable for machine learning. It supports clean binary labels, standard metrics such as AUROC and AUPR, and model families that can reuse increasingly powerful protein representations. However, the biological object we ultimately want is not a collection of isolated edge decisions. It is an interactome: a sparse, modular, functionally organized graph whose topology supports pathway activity, protein complexes, regulatory hubs, and disease-relevant perturbation effects. A model that classifies individual pairs well may still assemble those predictions into a graph that is too dense, poorly modular, or biologically incoherent.

Recent PPI modeling has advanced along several lines. Sequence and protein language model based methods learn interaction signals directly from amino-acid sequences or pretrained protein representations, including pair-aware systems such as [PLM-interact](../literature/notes/01_Papers/models/01_sequence_plm_pair_prediction/2025_nature_communications_plm_interact_extending_protein_language_models_to_predict_protein_protein_interactions.md), [PPLM](../literature/notes/01_Papers/models/01_sequence_plm_pair_prediction/2026_nature_communications_a_paired_sequence_language_model_for_protein_protein_interaction_modeling.md), and [MINT](../literature/notes/01_Papers/models/01_sequence_plm_pair_prediction/2026_nature_communications_learning_the_language_of_protein_protein_interactions.md). Structure and interface oriented methods use predicted complexes, residue contacts, or docking-like evidence to make interaction predictions more physically grounded, as in large-scale human proteome efforts such as [Predicting Protein-Protein Interactions in the Human Proteome](../literature/notes/01_Papers/models/02_structure_interface_design/2025_science_predicting_protein_protein_interactions_in_the_human_proteome.md). Graph and network representation methods treat observed interactomes as meaningful biological structure and can improve missing-edge prediction or module discovery, as shown by graph-native work such as [DNE](../literature/notes/01_Papers/models/03_network_topology_and_retrieval/2024_science_advances_deep_representation_learning_of_protein_protein_interaction_networks_for_enhanced_pattern_discovery.md). These directions are complementary, but they also leave a common gap: progress at the pair, interface, or observed-network level does not automatically solve inductive reconstruction of a realistic PPI graph for proteins whose target graph topology is not available at inference time.

This gap is made explicit by [PRING](../literature/notes/01_Papers/data/01_benchmarks_and_leakage/2025_neurips_pring_rethinking_protein_protein_interaction_prediction_from_pairs_to_graphs.md), a benchmark that evaluates PPI predictors by the quality of the reconstructed graph rather than by pairwise labels alone. PRING covers `21,484` proteins and `186,818` interactions across four species, applies leakage-reduction controls, and evaluates both topology-oriented and function-oriented graph tasks. Its key result is not simply that some models outperform others. The important finding is that strong pairwise-style predictors remain weak graph reconstructors. On Human intra-species reconstruction, `PLM-interact (650M)` is the strongest overall baseline, but its graph similarity remains only `0.396`, `0.350`, and `0.491` under the BFS, DFS, and random-walk topology settings. Its relative density is `1.64`, `2.03`, and `1.76`, indicating that the predicted graphs are consistently over-dense.

These numbers reveal a pair-to-graph gap. Pairwise prediction asks whether a specific edge is plausible. Interactome reconstruction asks whether the entire set of predicted edges forms a biologically plausible graph. The second question is not reducible to the first. Edge probabilities can be locally reasonable while their thresholded aggregate produces the wrong density, creates artificial hubs, destroys clustering structure, or merges functional modules that should remain separate. Conversely, a conservative operating point may improve precision but underconnect pathways and miss biologically meaningful neighborhoods. The graph is therefore not a passive visualization of pairwise predictions. It is the object whose structure determines whether the predictions can support downstream biological interpretation.

This matters because many biological uses of PPI prediction are graph-level tasks. Protein complexes and pathways require the right pattern of connectivity among multiple proteins, not just a few correct edges. Community detection and GO enrichment depend on whether predicted neighborhoods are functionally coherent. Essential proteins are often studied through centrality, hubness, and network position, which can be distorted by over-dense or poorly calibrated predictions. PRING's function-oriented evaluations make this point concrete: even leading models recover only limited functional alignment between predicted and true communities, and predicted centrality distributions do not fully preserve the separation between essential and non-essential proteins. In these settings, an isolated pair classifier is only an intermediate component. The scientific claim depends on the assembled graph.

The central research problem of this project is therefore: how can we reconstruct a biologically realistic PPI graph for an unseen protein set from intrinsic protein features, without using the target graph topology as input? Intrinsic features may include sequence, structure-derived representations, or pretrained protein language model embeddings, but the reconstructed graph must be inferred inductively. The model should not rely on target-test edges, degrees, neighborhoods, or community labels, because those are precisely the quantities the task asks us to recover. This distinction separates inductive interactome reconstruction from transductive link prediction on an observed graph.

A useful solution to this problem should satisfy four high-level requirements. First, it should preserve the strict inductive setting: target graph topology is evaluation signal, not input signal. Second, it should remain grounded in pairwise biochemical evidence, because an unconstrained graph-realism objective could otherwise produce plausible-looking but unsupported edges. Third, it should make graph realism a primary object of study, including density, hub structure, local clustering, global connectivity, and functional organization. Fourth, it should be evaluated in a way that exposes the mismatch between pair-level metrics and graph-level utility, rather than hiding that mismatch behind a single classification score.

Framed this way, PPI prediction becomes more than binary classification over protein pairs. It becomes inductive graph reconstruction from protein-intrinsic information: a task where the goal is not only to rank candidate interactions, but to assemble them into an interactome that is structurally and biologically credible. The research significance lies in closing this gap between local evidence and global biological organization. If pairwise predictors continue to improve without graph-level alignment, they may become better edge scorers while remaining unreliable network models. A graph-aware formulation gives the field a sharper target: not merely predicting whether two proteins interact, but reconstructing the interaction network in which biological function emerges.
